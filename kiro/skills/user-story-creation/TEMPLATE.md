# User Story Prompt Template

## Instructions

Use this template to create well-structured User Stories that follow Agile best practices. Fill in each section with specific, actionable information.

Use the Product Requirement Document (PRD) to understand the scope of this User Story.
If a PRD document is not provied. Ask for it before continuing.

### Guidelines

- Analyze the current User Story context: Review the work item details, related documentation, and any linked code repositories.
- Ask questions one at a time: Present a single, focused question and wait for the response before proceeding. Each question should:
  - Be specific and actionable
  - Include your recommended answer based on similar work items, documentation, or best practices
  - Reference relevant context from Jira, Confluence, or Bitbucket when applicable
- Build shared understanding: Summarize key decisions and open questions periodically.
- Be relentless but respectful: Continue questioning until all ambiguities are resolved, but remain collaborative and constructive in your approach.
