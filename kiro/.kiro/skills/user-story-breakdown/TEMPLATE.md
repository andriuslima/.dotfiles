---

## Breakdown Checklist

Before finalizing, verify:

- [ ] Every story is a vertical slice (spans all necessary layers)
- [ ] Every story delivers demonstrable user value independently
- [ ] Every story can be deployed on its own
- [ ] No horizontal slices exist (no "just database" or "just UI" stories)
- [ ] All user workflows from the PRD are covered
- [ ] Dependencies between stories are identified and documented
- [ ] Stories are small enough for a single sprint
- [ ] Stories are ordered by suggested implementation sequence
